# مكتبة التميّز

مكتبة عربية تضم 624 موردًا في التقويم والتعليم، مع بحث وتصنيفات وزر «فتح داخل المنصة» لكل مورد.

## العمل بالكامل من المتصفح

- عدّل ملفات HTML وCSS وJavaScript مباشرة باستخدام محرر GitHub.
- النشر تلقائي من فرع main ومجلد الجذر باستخدام GitHub Pages.
- لا يحتاج الموقع إلى تشغيل خادم أو تثبيت برنامج على جهازك.
- الملفات المحفوظة متاحة في files، وبقية الموارد مرتبطة بمصادرها الأصلية.
- بعض المواقع الخارجية تمنع التضمين؛ يمكن استخدام زر فتح الأصل.
- المفضلة والملاحظات تحفظ في متصفح المستخدم ولا تتزامن بين الأجهزة.

المحتوى والملفات لأصحابها، ولا تمنح هذه المكتبة ترخيصًا لإعادة بيعها.
